◆ 表示アプリ名
Sad2Key

◆ カテゴリ
Input Tool / 入力支援

◆ 概要
Nintendo Switch Pro Controller / Joy-Con の入力をキーボード入力へ変換する Windows 向け controller-to-keyboard mapper です。
Switch系コントローラーの HID 直接読み取り、JoyToKey形式 .cfg の読み書き、同時押し、短押し／長押しに対応しています。

◆ 詳細
Sad2Key は、Bluetooth接続した Nintendo Switch のコントローラーでゲームやお絵かきソフトをキーボード操作するための desktop application です。
JoyToKey で発生していた接続の不安定さや入力変換の不具合を回避するため、hidapi でコントローラーを直接読み取る経路を持っています。
JoyToKey の .cfg プロファイルをそのまま読み込み・編集・保存でき、未対応の行は原文のまま保持するため既存の設定を壊しません。
修飾キーを共有する同時押し（Ctrl+Z と Ctrl+- など）でも、最後の1つを離すまで修飾キーを押したままにする参照カウント方式でキーを送信します。

◆ 主な機能 / Features
・Pro Controller / Joy-Con L / Joy-Con R の HID 直接読み取り
・JoyToKey形式 .cfg の読み込み・新規作成・保存
・最大4キーの同時押し（修飾キー共有時も途中で離れない）
・押した長さで割り当てを切り替える短押し／長押し
・行をダブルクリックして開くマッピング編集画面（キーを押して取り込み）
・Joy-Con 単体使用時のスティック横持ち回転
・押されている入力をアクセント色で表示する入力モニタ
・Dark / Light テーマ切替
・exe と同じフォルダに設定を保存するポータブル構成
